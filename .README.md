# Ingeniería de Datos: ETL de ADManager

Este repositorio transforma logs del bot en un CSV idempotente de reseteos de
ADManager. Implementa las reglas de negocio de la Tarea 1, Parte 2.

Desde la terminal Linux, con uv instalado y los logs en `data/input/`:

```bash
uv sync --locked
uv run etl --all
uv run etl --date 2026-09-01
uv run pytest
```

La salida se escribe en `data/output/tabla_reporte_bot.csv`. Consultar
[README.md](README.md) para instalación, parámetros, diseño y reglas completas.
